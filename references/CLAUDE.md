# Referencias del juego — references/

Datos crudos extraídos del juego y la wiki. Solo lectura — no editar ni reorganizar sin autorización.

## Contenido

| Carpeta | Qué contiene |
|---|---|
| `game-ui/` | Descripciones de habilidades por warframe, extraídas de la UI del juego |
| `wiki/` | Datos de mecánicas, módulos y sistemas extraídos de la wiki de Warframe |
| `visual/mods/` | Imágenes de mods para referencia visual |
| `visual/screenshots/` | Capturas del juego (UI del arsenal, modding screen) |
| `visual/web-rips/` | HTML/CSS extraídos de la web del juego |

## Cuándo consultar

- `game-ui/<Warframe>.md` → texto canónico de habilidades para modelado semántico
- `wiki/mechanics/` → fórmulas y mecánicas del juego para validar el engine
- `wiki/systems/` → datos de sistemas específicos (incarnon, archon shards, etc.)
