# Overview — Backlog y registros transversales

Documentos de alcance global que no pertenecen a un dominio funcional específico.

## Documentos

| Archivo | Rol | Estado |
|---|---|---|
| [`impact-matrix.md`](impact-matrix.md) | Backlog técnico y matriz de dependencias físicas — **lectura obligatoria antes de cambios de arquitectura** | activo |

## Principio

`overview/` contiene dos tipos de documentos:
- **Mapas de impacto activos** — referencias cruzadas de qué afecta qué en el proyecto.
- **Registros de auditoría histórica** — capturas del estado del corpus documental en momentos clave, útiles para entender por qué la estructura es como es.

No es un dominio funcional. No tiene CLAUDE.md propio — aplica `docs/CLAUDE.md`.
